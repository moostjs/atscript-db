# i18n — translated `/meta`, errors and client preflight (0.1.170)

moost-db serves each request in its language once the app registers moost's translator. Nothing to configure in moost-db; the db-client takes a `locale`.

## Quick start

```ts
// server
import { setTranslator } from "moost";

setTranslator({
  en: {}, // source language FIRST = default for requests without Accept-Language
  de: {
    Title: "Titel",
    Archive: "Archivieren",
    MIN_LENGTH: "Mindestens {min} Zeichen",
    UNIQUE: "{fields} ist bereits vergeben",
  },
});

// browser
import { Client } from "@atscript/db-client";
const todos = new Client<typeof Todo>("/todos", { locale: () => i18n.locale });
```

Function translators (i18next, …), `locales`, `useTranslate()`: moost i18n docs (moostjs skill).

## Rules

| #   | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Ids:** annotation texts and action `label` / `description` / `promptText` → the text itself; built-in validator messages → their code (`MIN_LENGTH`, template with `{param}`s); db validator messages → `DB_VALIDATOR_MESSAGES` codes; `disabled` predicate reasons → the text itself; `DbError` → body `code` (`CONFLICT`, …) + entry codes (`UNIQUE`, `FK_MISSING`, `FK_RESTRICT`); anything else → its text.                                                                                                                                                                                  |
| 2   | **`/meta` and `/meta/form/:name`** are translated LAST (after `applyMetaOverlay`, `hasField`, own-path): `type` + `decorations` texts at any depth, actions' `label` / `description` / `promptText` (`$1` / `$N` kept — translations must keep them), and `type.$i18n` = translated templates of EVERY catalog registered with `registerMessages` (validator + db, plus app codes, UI strings, auth messages — all public to any client; only those differing from English, `{param}`s kept) + expression literal texts. Absent when empty.                                                        |
| 3   | **Locale** = `Accept-Language` negotiated by `MoostHttp` against the translator's locales; no header / unknown language → first locale. Source language first ⇒ those requests get the untranslated bytes. No translator ⇒ byte-identical responses, no `Vary: Accept-Language`.                                                                                                                                                                                                                                                                                                                   |
| 4   | **Caching:** ETag per language, `Vary: Accept-Language` added; 304 per language. The translated payload is memoized per (payload, translator generation × locale) — a translator must answer the same text for the same id + locale. Wording that depends on tenant/user → override `metaTranslation()` → `false`.                                                                                                                                                                                                                                                                                 |
| 5   | **Error bodies** are translated by moost's default `transformErrorBody` (entries by `code` + `params`, else text; top `message` by body `code`, else first entry's). `code` / `params` never change — branch on them, never on `message`.                                                                                                                                                                                                                                                                                                                                                          |
| 6   | **db validator errors carry codes since 0.1.170** (was `CUSTOM` + `custom: true`); English text unchanged. Codes: `GEO_POINT_SHAPE`, `GEO_LONGITUDE_RANGE {value}`, `GEO_LATITUDE_RANGE {value}`, `FIELD_OP_ON_DERIVED`, `FIELD_OP_CONTEXT`, `FIELD_OP_NOT_NUMERIC`, `FIELD_OP_NOT_FINITE {operand}`, `NAV_NULL {field}`, `NAV_PATCH_PLAIN_VALUE {relation, field}`, `NAV_PATCH_NOT_ARRAY {field}`, `PATCH_UNKNOWN_OPERATOR {operators}`, `PATCH_OPERAND_NOT_ARRAY {op}`, `PATCH_ITEM_NOT_OBJECT {op, index}`, `PATCH_KEY_REQUIRED {op, index, field}`, `PATCH_FIELD_REQUIRED {op, index, field}`. |
| 7   | **db-client `locale`** (string or getter, read per request) → `Accept-Language` unless `headers` has one. `meta()`, the validator and action forms are cached for ONE locale: a switch reloads them on the next call; the meta store keeps one entry per locale (`<key>#<locale>`) → switch back = 304. Held objects don't update — remount views on locale change. One client per locale; in SSR one client per request (never share one with a locale getter across concurrent requests).                                                                                                        |
| 8   | **Preflight errors** are translated with `type.$i18n` (`createClientValidator(meta)` / `client.getValidator()`; `new ClientValidator(type, { messages })` by hand); `ClientValidationError` entries keep `code` + `params`.                                                                                                                                                                                                                                                                                                                                                                        |
| 9   | **Not translated:** labels derived from field names (no id — add `@meta.label`); `client.getActionForm()` returns a deserialized type without `$i18n`.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 10  | **`disabled` reasons are translated by moost-db** (0.1.170) wherever they reach a client: `$disabledReasons`, `/meta/actions` `disabledReasons`, `summary()` `skipped[].reason` (query target or `onDisabledRows: 'skip'`), the 409 `reason` / `reasons` / `message`. Return SOURCE text from the (pure) predicate; never translate inside it.                                                                                                                                                                                                                                                     |
| 11  | Load every language before `listen()` or call `setTranslator` again after loading (new generation invalidates every memo).                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
